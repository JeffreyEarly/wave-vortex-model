#  k

Compact `Nkl`-by-1 x-wavenumber vector in $$\mathrm{rad\,m^{-1}}$$.


---

## Description
Real valued property with dimension $$kl$$ and units of $$\mathrm{rad\,m^{-1}}$$.

## Discussion

`k` is an `Nkl`-by-1 column vector in radians per meter.
