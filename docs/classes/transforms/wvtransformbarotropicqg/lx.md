#  Lx

Periodic domain length in the x direction.


---

## Description
Real valued property with no dimensions and units of $$\mathrm{m}$$.

## Discussion
Periodic domain length in the x direction.

`Lx` is the first element of the constructor's domain-size vector and has units of meters.
