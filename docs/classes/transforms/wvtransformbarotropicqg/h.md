#  h

Equivalent depth associated with a vertical mode.


---

## Description
Real valued property with no dimensions and units of $$m$$.

## Discussion
Equivalent depth associated with a vertical mode.

For three-dimensional transforms, `h` contains one value per vertical mode in meters. For `WVTransformBarotropicQG`, `h` is the scalar equivalent depth supplied at construction; its default is `0.8` m.
