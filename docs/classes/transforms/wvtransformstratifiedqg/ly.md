#  Ly

Periodic domain length in the y direction.


---

## Description
Real valued property with no dimensions and units of $$\mathrm{m}$$.

## Discussion
Periodic domain length in the y direction.

`Ly` is the second element of the constructor's domain-size vector and has units of meters.
