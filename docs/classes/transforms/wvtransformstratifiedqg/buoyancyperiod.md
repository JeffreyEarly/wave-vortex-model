#  buoyancyPeriod

Shortest buoyancy period in seconds.


---

## Discussion
Shortest buoyancy period in seconds.

The value is computed from the largest sampled buoyancy frequency as $$T_N=2\pi/\sqrt{\max(N^2)}$$.
