#  K2

Squared horizontal angular wavenumber on the coefficient grid.


---

## Description
Real valued property with dimensions $$(j,kl)$$ and units of $$rad^2 m^{-2}$$.

## Discussion
Squared horizontal angular wavenumber on the coefficient grid.

`K2` has `spectralMatrixSize`, units of radians squared per square meter, and is defined by $$K_h^2=K^2+L^2$$.
