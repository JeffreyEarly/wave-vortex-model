#  quasigeostrophicSpatialState

Return interior and two-endpoint fields in the shared QG spatial convention.

> Developer documentation: this item describes internal implementation details.


---

## Returns
+ `q`  full QGPV including its mean
+ `u`  zonal velocity
+ `v`  meridional velocity
+ `b`  surface and bottom displacement anomalies
+ `ub`  endpoint zonal velocity
+ `vb`  endpoint meridional velocity
+ `phiHat`  nonzero compact streamfunction samples
