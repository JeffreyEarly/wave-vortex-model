#  rotationRate

Planetary rotation rate in radians per second.


---

## Description
Real valued property with no dimensions and units of $$\mathrm{rad\,s^{-1}}$$.

## Discussion
Planetary rotation rate in radians per second.

The constructor default is $$7.2921\times10^{-5}\ \mathrm{rad\,s^{-1}}$$. Together with `latitude`, it determines `f`, `beta`, and `inertialPeriod`.
