#  planetaryRadius

Radius of the rotating planetary body in meters.


---

## Description
Real valued property with no dimensions and units of $$\mathrm{m}$$.

## Discussion
Radius of the rotating planetary body in meters.

The constructor default is `6.371e6` m, the mean radius used for Earth. This value enters the beta-plane relation for `beta`.
