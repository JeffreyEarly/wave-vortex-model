#  beta

Meridional gradient of the Coriolis parameter.


---

## Description
Real valued property with no dimensions and units of $$\mathrm{rad\,m^{-1}\,s^{-1}}$$.

## Discussion
Meridional gradient of the Coriolis parameter.

The transform computes $$\beta=2\Omega_\mathrm{planet}\cos(\phi)/R$$. Its units are radians per meter per second.
