#  N0

Constant buoyancy frequency in radians per second.


---

## Description
Real valued property with no dimensions and units of $$rad s^{-1}$$.

## Discussion
Constant buoyancy frequency in radians per second.

For `WVTransformConstantStratification`, the constructor default is `5.2e-3` rad/s and $$N^2=N_0^2$$ throughout the domain.
