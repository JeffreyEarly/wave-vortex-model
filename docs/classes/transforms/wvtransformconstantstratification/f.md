#  f

Coriolis parameter in radians per second.


---

## Description
Real valued property with no dimensions and units of $$\mathrm{rad\,s^{-1}}$$.

## Discussion
Coriolis parameter in radians per second.

The transform computes $$f=2\Omega_\mathrm{planet}\sin(\phi)$$ from `rotationRate` and `latitude`.
