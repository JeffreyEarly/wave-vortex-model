#  Nz

Number of vertical spatial grid points.


---

## Description
Real valued property with no dimensions and is dimensionless.

## Discussion
Number of vertical spatial grid points.

`Nz` is the third element of a three-dimensional transform's resolution vector and equals `length(z)`.
