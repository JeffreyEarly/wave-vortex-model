#  h_0

Geostrophic equivalent-depth scale for each vertical mode.


---

## Description
Real valued property with dimension $$j$$ and units of $$\mathrm{m}$$.

## Discussion
Geostrophic equivalent-depth scale for each vertical mode.

`h_0` is an `Nj`-by-1 vector in meters used to normalize the zero-frequency geostrophic modes.
