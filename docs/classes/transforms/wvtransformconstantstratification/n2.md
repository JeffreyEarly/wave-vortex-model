#  N2

$$N^2(z)$$, squared buoyancy frequency of the no-motion density, $$N^2\equiv - \frac{g}{\rho_0} \frac{\partial \rho_\textrm{nm}}{\partial z}$$


---

## Description
Real valued property with dimension $$z$$ and units of $$rad^2 s^{-2}$$.
