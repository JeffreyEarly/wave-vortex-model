#  k_f

Center wavenumber $$k_f$$ of the forced band in radians per meter.


---

## Type
+ Class: `double`
+ Size: `(1,1)`

## Description
Real valued property with no dimensions and units of $$\mathrm{rad\,m^{-1}}$$.

## Discussion

The selected band has width `wvt.kRadial(2)-wvt.kRadial(1)`.
