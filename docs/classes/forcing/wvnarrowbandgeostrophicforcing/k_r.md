#  k_r

Effective arrest wavenumber $$k_r$$ in radians per meter.


---

## Type
+ Class: `double`
+ Size: `(1,1)`

## Description
Real valued property with no dimensions and units of $$\mathrm{rad\,m^{-1}}$$.

## Discussion

Supplying `r` takes precedence over the `k_r` option.
