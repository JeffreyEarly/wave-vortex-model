#  r

Configured linear drag rate in $$\mathrm{s^{-1}}$$.


---

## Description
Real valued property with no dimensions and units of $$\mathrm{s^{-1}}$$.

## Discussion

The constructor default is `1/(200*86400)`, corresponding to a
200-day time scale.
