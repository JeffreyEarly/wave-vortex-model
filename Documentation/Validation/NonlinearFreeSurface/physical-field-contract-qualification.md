# Physical field contract qualification

> Historical evidence. This report describes the retired weak/pressure implementation or its comparison studies. The executable solvers have been removed; see the [direct runtime qualification](direct-runtime-qualification.md) for the current implementation. Historical source links refer to revision `7b9ccda7`.

`UnitTests/TestFreeSurfacePhysicalContract.m` qualifies the public field changes at root commit `a25305d5` on a constant-stratification 4-by-4-by-65 mixed state with both wave signs, two horizontal surface slopes, and valid MDA mean endpoint offsets. This increment changes only this test and note; no core fixes were needed.

The four focused methods cover:

- Independent physical mapping from the modal `u_hat`, `v_hat`, and `w_hat`, moving `z_physical`, interior displacement, and `w_i`. The independently mapped physical fields recover the original modal state through `projectFields` within $2\times10^{-7}$ relative quadratic norm. `p_linear` remains the modal pressure and bare `p` is rejected. The existing quadratic `totalEnergy` agrees with the hatted-field quadratic integral within $2\times10^{-13}$ relative tolerance.
- Disjoint wave, balanced (including MDA), and inertial contributions add to the total physical and hatted fields. Warming the nonzero balanced velocity cache, changing $t$, and then changing $t_0$ gives the fresh total-geometry reconstruction each time; the hatted balanced velocity is unchanged. Component partitions of `p_full` and `z_physical` are explicitly rejected.
- The full pressure boundary is $p_s/\rho_0=g\zeta-N^2\zeta^2/2$, and nonlinear energy includes physical-volume kinetic energy, $N^2\eta^2/2$, and the cubic surface correction $-N^2\zeta^3/6$. The analytical nonlinear energy agrees within $2\times10^{-13}$ relative tolerance and differs from the quadratic inventory. A manufactured physical pressure-gradient source with zero surface potential changes pressure by $\rho_0\chi$ within $3\times10^{-7}$ Pa; its equivalent reference-coordinate source gives the same change. Adding/removing forcing and changing wave coefficients invalidate the warmed `p_full` cache.
- Native NetCDF writing stores `fieldConvention="physical-velocity-full-c1"`; restoration retains the marker, coefficients, both clocks, bitwise stored modal arrays and derivative matrix, and the physical/hatted field interpretations. Full pressure and nonlinear energy reconstruct consistently after restoration. The restored `verticalModes` provider is empty; the inspected file-reader path reconstructs directly from saved scientific operators rather than calling `fromStratification`. This is bounded stored-state restoration evidence, not a separate performance profile of every constructor call.

All four methods passed. An initial cache-change assertion selected `u_balanced`, which is identically zero for the fixture's zonal balanced mode; it was corrected to the nonzero `v_balanced` component, and only that affected method was rerun. The other three successful methods were not repeated. Code Analyzer and whitespace/scope checks passed. No package metadata, released snapshots, existing source/tests, or generated documentation were edited. These tests qualify the stated field, cache, diagnostic, and file semantics; they do not add nonlinear trajectory or conservation qualification.
