# Manuscript source-projector controls

`TestFreeSurfaceManuscriptProjection` qualifies the existing generic four-volume-field `projectSources` against the manuscript independently of either nonlinear stage or a constrained weak solve. The implementation baseline is `a2088e8a`. The manuscript inspected was `literature/ape-apv-free-surface/main.tex` at commit `311ebf5`, SHA-256 `52227df2683a76181e079dd98d52866196ea227439216acb4d3f7b66d537b813`.

The six cases combine three controls with two 8-by-8-by-65 constant-stratification inventories. Both active endpoints, APV/MDA/inertial counts 2, and clocks t=327 s and t0=-17 s are used throughout. One inventory has repeating per-wavenumber wave prefixes [3,2,0], including padding and a zero-wave page; the other omits waves entirely.

- Arbitrary smooth manufactured sources have analytically specified nonzero Fourier coefficients and horizontal means. An independent 96-point Gauss-Legendre rule integrates the retained vertical-mode polynomials via barycentric evaluation. APV source functionals use their manuscript endpoint terms. The boundary-normalized zero-APV coefficients use a small independently assembled signed generalized-energy Gram matrix and source pairing. The two wave signs use explicit analytic polarizations in the generalized-energy source functional; inertial and signed MDA formulas include the separate mean and phase conventions. No stored forward/pairing/solve matrices, runtime polarization helper, source projector or weak solve supply the oracle.
- Analytic polynomial pressure gradients have either zero or nonzero surface trace and zero bottom pressure. Interior cancellation leaves only the wave contribution `-1i*kappa*G(surface)*p(surface)/(2*rho0)` multiplied by the inverse wave phase. Zero-surface gradients cancel in every family; nonzero-surface gradients give nonzero waves where retained. This checks the explicit boundary term in `eq:projection-wave-generic-g-form` without subtracting an incomplete balanced expansion.
- Each separate retained family and a mixed state obey the full linear equations. An analytically differentiated modal phase state supplies field time derivatives; momentum and displacement rates are independently evaluated from Coriolis, pressure gradients, buoyancy and vertical velocity. Their residual is projected, and the SSH equation is checked separately. This projects the complete linear residual; it does not incorrectly interpret the four-volume-field projection of a total linear tendency as a five-field state inverse or add isolated pressure loading to an already phase-evolved state.

All six cases passed on MATLAB R2025b Update 4 with the pinned beta.4 dependency exports in 6.8658 s. Maximum complete-linear field residual divided by the test's state scale was 1.18848e-14 for variable wave counts and 5.99565e-17 for the empty-wave inventory. Source comparisons passed 3e-9 relative/2e-12 absolute tolerances, and pressure controls passed 2e-9 relative/2e-13 absolute tolerances. Code Analyzer and whitespace checks were clean. Only this class was run; no runtime source was changed.

These tests establish the bounded source-projector and linear-cancellation controls. They do not validate the assembled Appendix C nonlinear residual, a nonlinear pressure closure, arbitrary stratification, or trajectory/conservation behavior. The independent source oracle evaluates the manuscript generalized-energy functional directly; the G-form formula that subtracts a balanced projection requires care when that balanced expansion is truncated.
